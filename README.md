# homebrew-jot

Homebrew tap for [Jot](https://github.com/lsuryatej/jot), a native plain-text
scratchpad for macOS.

```bash
brew install lsuryatej/jot/jot
```

Updating a formula here does not update anyone's installed copy by itself —
running `brew upgrade jot` (or Homebrew's own periodic update check) does
that, by re-reading this tap.
